Its CSS rules (`.hnd`, `.htxt`, `.hcard`) were removed from the stylesheets in the cleanup; to bring the section back, restore them from git history (commit `a781e25`).
`bold-process/` holds the bold card version of the "how we work" section (`39-bold-process.css`). Removed; the section is back to its original design. To bring it back, copy the file to `src/css/` and link it after `38-bold-hero-cards.css`.
`loader-ideas/` is a preview page of four loading-screen ideas in the bold card style (deal, spinning card, shuffle, name plate), with the current loader on top for comparison. Open it through a server from the site folder (e.g. `python3 -m http.server 8083`, then `/drafts/loader-ideas/`). Not loaded by the build; nothing in the live loader has changed.
`glow-shader/` holds the WebGL background glow (`17-glow-shader.js`) that used to sit behind the hero; it was taken off the page. This copy only draws while the hero is on screen. To bring it back, put the file in `src/js/`, add its `<script>` to the js block in `index.html`, add `<canvas class="glow" id="glow" aria-hidden="true"></canvas>` inside the hero stage, and add its rule to the CSS: `.glow{position:absolute;top:0;left:0;width:100%;height:100%;z-index:-1;pointer-events:none;mix-blend-mode:screen;opacity:.15}`.
`unused-assets/` holds images the live page no longer uses (the cream logo, the logo mark and PNG logo from earlier card backs, the rule-card grain `texture-3.svg`, and the asymmetric card back `texture-5.svg`). Archived drafts above still point at them under `assets/img/`; copy one back there if you restore such a draft.
